# DCR Enabled Build v1.1.2

This release distributes the provisioning template and source for the Atlassian Rovo MCP v2 integration with Microsoft 365 Copilot Cowork. It is not a universal, preconfigured Microsoft 365 installer.

## Downloads

- `dayour-atlassian-cowork-1.1.2.tgz`: focused provisioning template, also published as `@dayour/atlassian-cowork` in GitHub Packages.
- `atlassian-cowork-v1.1.2-source.zip`: complete tagged repository, including the Docusaurus wiki source.
- `SHA256SUMS.txt`: SHA-256 checksums for both assets.

Neither archive contains the operator's generated environment or tenant-bound installation ZIP. Extract the template, create your environment from the example, and run Toolkit provisioning to produce your own installer. GitHub Packages is an authenticated npm distribution channel for the same template, not a second app installation system.

## Fix

Toolkit now runs `dcr/register` before packaging. The generated authentication configuration is bound through `OAuthPluginVault.referenceId`. The manifest app ID uses the created app identity, and the tool catalog uses its exact ZIP-relative path. Personal-scope acquisition and explicit title verification address the observed stale shared-title collision.

## Installation and evidence

Follow [DCR Enabled Build v1.1.2](https://dayour.github.io/atlassian_cowork/reproduction/dcr-enabled-build-v1-1-2) for configuration, upload, consent, verification, and troubleshooting.

DCR registration, package validation, consent, and authorization-code callback were verified in the test environment. Authenticated tool invocation was owner-reported. Refresh-token renewal, clean omitted-auth automatic DCR, and cross-tenant distribution remain unverified. This is an independent reproduction, not an official Microsoft or Atlassian distribution.

The documentation build has known upstream dependency audit findings; the focused template package has no npm runtime dependencies. Do not interpret successful packaging as an end-to-end authentication certification.
